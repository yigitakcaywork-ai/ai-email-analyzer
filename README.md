# AI Email Analyzer

An AI-powered workflow that analyzes incoming emails, categorizes them by priority, detects intent, and generates a professional draft reply using AI.

## Features

- Email categorization
- Priority detection
- AI-generated replies
- Workflow automation with n8n
- Google Gemini integration

## Tech Stack

- n8n
- Google Gemini API
- GitHub
